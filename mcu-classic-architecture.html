MCU 经典架构（Cortex-M）

CPU 调度 + 存储器 + 外设 + 时钟 + 总线 + 中断 —— 集成在一个芯片里，串起「C 语言 → 功能」
CPU（调度） 时钟/电源 中断 调试 存储器 总线 外设

三者关系

  • • C 语言：设计功能、表达"怎么实现"
  • • CPU：取指/译码/执行，调度程序
  • • MCU：CPU+存储+外设，实现功能

存储分工（易失/非易失）

  • • Flash：存程序，断电还在（非易失）
  • • SRAM：存变量，断电即丢（易失）
  • • 这就是"程序跑起来"的底料

为什么叫"微控制器"

  • • CPU + 存储 + 外设 + 时钟 + 总线
  • • 全集成在一颗芯片里（单片机）
  • • 一个 MCU 就能扛一个完整控制任务
